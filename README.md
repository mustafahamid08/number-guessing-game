# 🎯 Number Guessing Game

A Python-based number guessing game where players try to guess a randomly generated number within the fewest attempts possible.

## 🚀 Project Overview

This project generates a random number between 1 and 100 and challenges the user to guess it. The game provides hints after each incorrect attempt, helping the player reach the correct answer.

Built to practice:
- Python Fundamentals
- Loops and Conditional Statements
- User Input Handling
- Random Number Generation
- Problem Solving Skills

## ✨ Features

✔ Random Number Generation  
✔ Higher / Lower Hints  
✔ Attempt Counter  
✔ Interactive Command-Line Gameplay  
✔ Beginner-Friendly Python Project  

## 🛠 Technologies Used

- Python 3
- Random Module

## 🎮 How It Works

1. The computer generates a random number.
2. The player enters a guess.
3. The game provides hints:
   - Higher number please
   - Lower number please
4. The game continues until the correct number is guessed.
5. Total attempts are displayed at the end.

## ▶️ How to Run

```bash
python main.py
```
